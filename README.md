# essais

本文だけを、明朝体で、本のように読ませるサイトです。
目次も記事も縦組と横組を切り替えられ、既定は縦組です。

## 準備

Node.js 22.13 以上と pnpm が必要です。

```sh
pnpm install
```

## 執筆環境

```sh
pnpm write
```

ブラウザで http://localhost:8090 を開くと執筆画面が出ます。
執筆画面はこの PC の中だけで動き、外部からはアクセスできません。

画面には原稿かプレビューのどちらか一方を表示します。
右上の本のアイコンで、原稿とプレビューを切り替えます。
プレビューはサイトと同じ変換と組版で作るため、公開時の見た目をそのまま確認できます。
隣のアイコンで縦組と横組を切り替えられます。組方は原稿とプレビューで共通で、選んだ組方は次に開いたときも引き継がれます（既定は縦組）。
記法の一覧は、右上の「？」アイコンから開きます。
右上の矢印のアイコンでサイトを公開します（`pnpm run deploy` と同じ処理です。[docs/deploy.md](docs/deploy.md)）。

左上のアイコンで原稿の一覧を開きます。

- 一覧から原稿を選ぶと開きます。次に執筆画面を開いたときは、最後に開いていた原稿が表示されます。
- 新しい原稿は「新しく書く」から始め、題と日付、記事の名前を決めます。新しい原稿は下書きから始まります。名前は URL になるため、半角英小文字・数字・ハイフンで入力します。一度保存した原稿のURLは変更できません。
- 日付の隣の「下書き」に印を付けた原稿は、サイトに出ません（頁も、目次の項目も、画像も書き出しません）。公開するときは印を外します。一覧では題の横に「下書き」と表示されます。
- 開いている原稿は、一覧の下の「開いている原稿を消す」で削除できます。原稿のフォルダは画像ごと `.trash/<名前>-<日時>/` に移ります。
- 一覧の並びが、そのままサイトの目次の並びになります。行の左端（つまみ）をドラッグするか、右の矢印で順序を入れ替えます。新しい原稿は目次の末尾に追加されます。

編集内容は自動で保存されます。
⌘S（Windows では Ctrl+S）を押すと、即座に保存されます。
画像を本文の欄にドラッグ＆ドロップするか貼り付けると、記事のフォルダに保存され、本文に図の記法が挿入されます。
画面の下端には、本文の文字数と、四百字詰め原稿用紙に換算した枚数が表示されます。

## 開発とビルド

```sh
pnpm dev    # http://localhost:8080 でローカル確認（ファイル変更時に自動更新）
pnpm build  # _site/ に書き出し
```

`pnpm write` と `pnpm dev` は、別々のターミナルで同時に起動できます。

## ディレクトリ構成

```
src/posts/<名前>/index.md    原稿
src/posts/<名前>/*.jpg など  その記事の画像
src/posts/order.json         目次の並び
src/_data/site.json          サイトの名前と説明
```

原稿の頭には題と日付が入ります。下書きの原稿には `draft: true` も入ります。
執筆画面が書き込むため、手作業で書く必要はありません。

```markdown
---
title: "縦に読む"
date: 2026-10-24
---

本文……
```

`pnpm build` は、書き出す前に `_site/` を空にします（`pnpm dev` では空にしません）。

目次は、`src/posts/order.json` に原稿の名前を並べた順になります。
このファイルに載っていない原稿は、載っている原稿の後ろに、日付の古い順で並びます。

## デプロイ

`_site/` を Cloudflare に直接アップロードして公開します。
手順は [docs/deploy.md](docs/deploy.md) を参照してください。

## バックアップ

原稿（`src/posts/` の記事のフォルダと `order.json`）の写しを、Cloudflare R2 に取れます。
原稿を git に入れない場合は、これが原稿の控えになります。
手順は [docs/backup.md](docs/backup.md) を参照してください。

サイトの生成には 11ty（Eleventy）を使用しています。
