# essais

本文だけを、明朝体で、本のように読ませるサイトです。
目次も記事も縦組と横組を切り替えられ、既定は縦組です。

## 準備

Node.js 22.13 以上と pnpm が必要です。

```sh
pnpm install
```

## 執筆環境

```sh
pnpm write
```

ブラウザで http://localhost:8090 を開くと執筆画面が出ます。
執筆画面はこの PC の中だけで動作し、外部からはアクセスできません。

### 編集機能

原稿は公開時の見た目に近い WYSIWYG（リッチテキスト）形式で直接編集できます。
見出し、傍点、ルビ、注、縦中横などの組版要素は、上部のツールバーまたはショートカットから入力できます。

- **改行**: Enter で新しい段落、Shift+Enter で段落内改行になります。
- **空き**: 段落の間で Enter を重ねて空の段落を作ると、その数だけ一行の空きになります（Markdown では空行を重ねます。空行二つで一行の空き）。見出し・引用・箇条書きの前後と、本文の頭と末尾の空きは残りません。
- **入力補完**: 行頭で `## `、`> `、`- `、`1. ` などを入力すると、見出しや引用、箇条書きに自動変換されます（全角の ＃ や ＞ にも対応）。
- **要素の編集**: 設定済みのルビ、縦中横、図はクリックするとダイアログで修正できます。脚注の内容は本文末尾の欄で編集します。
- **Markdown ソース編集**: `<>` アイコンを押すと Markdown の直接編集モードに切り替わります（どちらの編集モードを使うかは次回起動時にも引き継がれます）。

右上のアイコンから縦組と横組の切り替え、書き方一覧（「？」アイコン）、サイトのデプロイ（矢印アイコン）が行えます。

### 原稿の管理

左上のアイコンから原稿一覧を開きます。

- **記事の選択・再開**: 一覧から原稿を選ぶと開きます。次回起動時は最後に編集していた原稿が自動で開きます。
- **新規作成**: 「新しく書く」から始め、題・日付・記事名（URLスラッグ）を入力します。名前は半角英小文字・数字・ハイフンで指定し、保存後の変更はできません。
- **下書き**: 「下書き」にチェックを入れた原稿は、サイト生成（ページ・目次・画像）から除外されます。
- **削除**: 一覧下部のボタンから、現在開いている原稿を削除できます。削除した原稿は Front Matter に `deleted: true` が付き、下書きと同様にサイト生成から除外されます。原稿フォルダと目次の位置は残るため、一覧の「消した原稿」から「戻す」で元に戻せます。
- **完全削除**: `pnpm purge` で、削除した原稿をまとめて完全に消去します（原稿フォルダ、目次の並び、R2 のバックアップ）。`pnpm purge --dry-run` で対象の確認だけを行えます。完全削除するまで、削除した原稿の名前は新しい原稿に使えません。
- **並び順**: 一覧の順序がそのままサイト目次の並び順になります。行左端のつまみをドラッグするか、右側の矢印で並び替えます。

### 保存と入力補助

- 編集内容は自動で保存されるほか、⌘S（Windows では Ctrl+S）で即座に保存できます。
- 画像を本文欄へドラッグ＆ドロップまたは貼り付けると、記事フォルダに保存され、図の記法が挿入されます。
- 画面下部に文字数と、四百字詰め原稿用紙に換算した枚数が常時表示されます。

## 開発とビルド

```sh
pnpm dev    # http://localhost:8080 でローカル確認（ファイル変更時に自動更新）
pnpm build  # _site/ に書き出し（実行前に _site/ を自動クリーン）
```

`pnpm write` と `pnpm dev` は、別々のターミナルで同時に起動できます。

### OGP 画像

`pnpm build`（と `pnpm run deploy`、執筆画面からの公開）では、記事ごとに縦組の OGP 画像を `og.png` として書き出します。
題・日付・本文の書き出しを 1200×630 に組み、Google Chrome の headless モードで撮ります（`pnpm dev` では作りません）。
Chrome が既定の場所に無いときは `ESSAIS_CHROME` でパスを指定します。見つからなければ画像なしでビルドを続けます。
撮った画像は `.cache/og/` に取っておき、内容の変わった記事だけを撮り直します。

`og:url` と `og:image` は絶対 URL が必要なため、`src/_data/site.json` の `url` に公開 URL（末尾のスラッシュなし）を設定したときだけ出力されます。

## ディレクトリ構成

```
src/posts/<名前>/index.md    原稿
src/posts/<名前>/*.jpg など  その記事の画像
src/posts/order.json         目次の並び
src/_data/site.json          サイトの名前と説明、公開 URL
```

原稿の先頭には Front Matter として題と日付が入ります（下書きの場合は `draft: true`、削除した場合は `deleted: true` が付与されます）。これらは執筆画面側で自動管理されるため、手作業で記述する必要はありません。

```markdown
---
title: "縦に読む"
date: 2026-10-24
draft: true
---

本文……
```

目次は `src/posts/order.json` に指定された順序で並びます。このファイルに記載のない原稿は、記載のある原稿の前に日付の新しい順で並びます。新しく書いた原稿は先頭に加わります。

## デプロイ

`_site/` を Cloudflare に直接アップロードして公開します。
手順は [docs/deploy.md](docs/deploy.md) を参照してください。

## バックアップ

原稿（`src/posts/` の記事フォルダと `order.json`）を Cloudflare R2 にバックアップできます。
手順は [docs/backup.md](docs/backup.md) を参照してください。

サイトの生成には 11ty（Eleventy）を使用しています。
